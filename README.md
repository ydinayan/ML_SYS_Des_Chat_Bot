# AI агент для ответов в чате 
Репозиторий для работы над ДЗ по ML Sys Design для банковского чат-ассистента. 

## 🎯 Цель проекта

Ускорить работу технической поддержки банка за счёт
автоматизации обработки типовых обращений клиентов.

## ⚙️ Основные функции

Ассистент решает три группы задач:

1. **Ответы на справочные вопросы**
   - Информация о продуктах и сервисах банка.
   - Ответы на типовые вопросы клиентов.

2. **Выполнение простых операций**
   - Формирование выписок.
   - Поиск операций в истории транзакций.

3. **Эскалация обращений**
   - Подключение специалистов второй линии поддержки
     для решения сложных вопросов.
