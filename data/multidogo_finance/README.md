# MultiDoGO Finance

Англоязычные сценарные диалоги клиента и оператора для учебного EDA банковской поддержки. Файлы взяты без изменений из [репозитория AWS MultiDoGO](https://github.com/awslabs/multi-domain-goal-oriented-dialogues-dataset/tree/baa30639c4b271f394b81443c842193407cdf26d). Лицензия CDLA Permissive и уведомление об авторских правах лежат рядом с данными. [Статья авторов](https://aclanthology.org/D19-1460/).

- `unannotated/finance.tsv` содержит 8 832 диалога и 157 229 реплик. Несмотря на расширение `.tsv`, файл использует запятую как разделитель. Поля `conversationId`, `turnNumber` и `authorRole` позволяют восстановить порядок реплик и роли участников.
- `paper_splits/splits_annotated_at_turn_level/finance/` содержит разметку клиентских реплик по намерениям и параметрам. В `train.tsv` 15 213 записей, в `dev.tsv` 2 167, в `test.tsv` 4 361.
- `paper_splits/splits_annotated_at_sentence_level/finance/` содержит разметку на уровне предложений. В обоих наборах с разметкой разделитель — табуляция. Несколько намерений в одной записи разделены строкой `<div>`.

На корпусе можно изучить длину диалогов, распределение намерений, заполненность параметров и примеры обращений вне домена. Для оценки по постановке проекта понадобятся отдельные данные с разметкой срочности, негатива и эскалации, документами базы знаний и эталонными результатами банковских операций.
